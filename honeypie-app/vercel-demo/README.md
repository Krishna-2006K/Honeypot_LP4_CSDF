# Vercel preview

Set this folder as the Vercel project's **Root Directory**. It is a static, view-only preview of the dashboard; the sample events use reserved documentation IP ranges.

The login lure on this deployment is visual only. Its button does not submit the entered fields, and the page does not send or store them. The SSH listener is not hosted here. Use the full Python app in the sibling `local` folder on a machine or container that can keep long-running listeners and audit storage available.
